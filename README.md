# ProjectCheckTool

親フォルダ配下にあるプロジェクトの進捗・課題・git 状態を俯瞰し、将来的には製造・修正・リリース等の実行までを担う管理ツール。

## 起動方法

```bash
npm install
npm run dev
# → http://localhost:3777
```

本番ビルドで動かす場合は `npm run build` → `npm run start`。

## 設計原則

- **ポータビリティ**: 管理対象ルートは「本リポジトリの親フォルダ（`..`）」を実行時に動的解決する。コード・設定に絶対パスを書かない。どの PC でもフォルダ構成が同じなら同じように動く。別の場所を管理したい場合のみ環境変数 `PROJECT_ROOT` で上書き可能（非常口）。
- **既定 read-only**: 現在の機能はすべて読み取り専用。書き込み・実行系の機能は承認ゲート必須で今後追加する。
- **秘密情報の不可侵**: `.env*`・鍵ファイル等は deny-list（`lib/security.ts`）で読み取り経路から恒久的に除外する。

## 現在の機能（Phase 1 MVP）

- 親フォルダ配下のプロジェクト自動検出（`.git` または `package.json` を持つフォルダ）
- プロジェクト種別の自動判定（Next.js / Electron / Node.js / ドキュメント・その他）
- git 状態ダッシュボード: 現在ブランチ、作業ツリー（変更・未追跡・競合）、リモート同期状態（ahead/behind）、最終コミット
- 健全性シグナル: CI・テストの有無、30 日以上更新のないプロジェクトの停滞アラート

## チーム運営

本プロジェクトは CEO「シャチョー」率いる AI チーム体制で開発している。運営規約は `CLAUDE.md`、活動記録は `ai-team/log/`、進捗は `progress.md` を参照。
